# Changelog

## [1.0.0] — 2026-11-17

First sealed GitHub Release of the educational cattle vision and welfare telemetry portfolio.

- **Pipeline** — YOLO cattle detection, posture / lighting / occlusion heuristics, DuckDB `cattle_telemetry`, and SQL calving analytics (`calving_analytics.py`).
- **Quality harness** — PyTest coverage in `test_eval.py` and `test_cattle_heuristics.py` (CPU-light, no YOLO weights required).
- **Docs** — README with UK farmer setup guide, architecture diagram, MIT licence, and educational disclaimers.
- **Release** — Tag-triggered GitHub Release with sdist, wheel, source zip, `SHA256SUMS.txt`, and build provenance attestations.
